> [!NOTE]
> some of the element names are already an option in settings, take note that the element names may change at anytime

> [!TIP]
> some ui elements like buttons can be hidden based on the specific text shown
>
> example is `button$Undo` where it hides buttons containing the english text "Undo"

# general element paths

* `avatar`
* `button`
* `card`
* `chip`
* `thumbnail`

# specific element paths with buffer strings

| element name                                                 | about                                                                                           | buffer string type 
|--------------------------------------------------------------|-------------------------------------------------------------------------------------------------|-------------------------------------------
| `bottom_sheet_list_option_temporary_clone$Unsubscribe`       | the unsubscribe option in the flyout menu, from the watch page for example                      | string literal
| `button$Ignore limit for today`                              | the button from shorts limit popup allowing you to ignore the limits you've set                 | string literal
| `button_inner$community_page`                                | the "quote" button in community posts that redirects to create a new post                       | buffer identifier
| `card$basic_content`                                         | automatically hides the card "We won't recommend videos from this channel" and similar variants | element_path of another element_path
| `compact_channel$search:`                                    | hides the channel card in search results (one with "Subscribe" and "View channel" buttons)      | buffer identifier
| `compact_video$Members only`                                 | targets "Members only" videos in a channel page                                                 | string literal
| `video_lockup$relatedH`                                      | targets related videos under the player in watch page                                           | buffer identifier
| `video_lockup$UCBR8-60-B28hp2BmDPdntcQ`                      | targets videos based on the channel id (example id is from official youtube channel)            | string literal and buffer identifier
